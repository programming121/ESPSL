# Eastern Sky Security — GitHub Pages display copy

This folder is a static, presentation-only copy of the Eastern Sky Private
Security Agency website. Upload the **contents** of this folder to a GitHub
repository and enable GitHub Pages from the repository root.

It runs with plain HTML, CSS and JavaScript—no PHP or database is required.
The enquiry forms open the visitor's email app when the PHP endpoint is not
available. For live enquiry storage, deploy the main project to a PHP/MySQL
host instead (see `DEPLOYMENT.md` in the parent project).
